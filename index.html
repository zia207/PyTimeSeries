PyTimeSeries — User Guide

A unified, tutorial-driven forecasting library — from Naive to PatchTST behind one API.

Install

pip install pytimeseries            # core
pip install "pytimeseries[ml]"     # + LightGBM/XGBoost/CatBoost, AutoARIMA
pip install "pytimeseries[dl]"     # + PyTorch, neuralforecast
pip install "pytimeseries[extra]"  # + arch, prophet, ruptures, hierarchicalforecast
pip install "pytimeseries[all]"
